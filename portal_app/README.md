# Θέμα 1: Διαχείριση Portal Εργαστηριακών Ασκήσεων
**Μάθημα:** Υπηρεσιοστρεφές Λογισμικό 2025-2026  
**Διδάσκων:** Ευάγγελος Σακκόπουλος

## Περιγραφή Project
Ένα αλληλεπιδραστικό υπηρεσιοστρεφές λογισμικό για τη διαχείριση και σύνθεση ομάδων εργαστηρίου. Οι χρήστες μπορούν να αναζητούν συνεργάτες με βάση κοινά ενδιαφέροντα και μαθήματα.

## Λειτουργίες
* **Social Feed:** Αποστολή, αναζήτηση και κατηγοριοποίηση posts.
* **Networking:** Προσθήκη χρηστών ως προσωπικές επαφές.
* **Authentication:** * Τοπικό σύστημα (Basic Authentication).
    * 3rd party login (Google/Facebook OAuth) μέσω της βιβλιοθήκης **Devise**.
* **Messaging:** Σύστημα άμεσων μηνυμάτων (Pop-up) για προσωπικές ή ομαδικές συνομιλίες.
* **Notifications:** Άμεση ενημέρωση χρηστών για νέα μηνύματα/αιτήματα.

## Τεχνολογίες
* **Backend:** Ruby on Rails
* **Database:** SQLite3 / PostgreSQL
* **Frontend:** Hotwire / Turbo (για τα notifications και τα pop-up μηνύματα)

## Οδηγίες Εγκατάστασης
1. `bundle install`
2. `rails db:migrate`
3. `rails server`
